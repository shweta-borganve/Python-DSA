# 💰 EXPENSE TRACKER SYSTEM

## 📖 ABOUT THE PROJECT

The **Expense Tracker System** is a Python-based command-line application that helps users manage their daily expenses efficiently. Users can add, view, search, update, delete, and calculate their expenses. All expense records are stored in a text file (`expenses.txt`) using Python file handling.

---

## ✨ FEATURES

- 🔐 User Login Authentication
- ➕ Add Expense
- 📋 View All Expenses
- 🔍 Search Expense by Category
- ✏️ Update Existing Expense
- 🗑️ Delete Expense
- 💰 Calculate Total Expense
- 📁 Store Expense Records in a Text File
- ⚠️ Exception Handling using `try` and `except`

## 📄 EXPENSE FILE FORMAT

Each expense is stored in the following format:

```
Date,Category,Amount,Description
```

### Example

```
28-07-2026,Food,250.0,Lunch
29-07-2026,Travel,100.0,Bus Fare
30-07-2026,Shopping,500.0,Dress
```

# 📚 LIBRARY MANAGEMENT SYSTEM

A **Python-based Library Management System** that allows users to manage library books efficiently using **File Handling**. This is a menu-driven console application developed to practice Python fundamentals, file operations, and CRUD (Create, Read, Update, Delete) functionality.

---

## 🚀 Features

- 🔐 Login Authentication
- ➕ Add New Book
- 📖 View All Books
- 🔍 Search Book by Book ID
- 📤 Issue Book
- 📥 Return Book
- ✏️ Update Book Details
- 🗑️ Delete Book
- 📊 Count Total Books
- 🚪 Exit Application

---

## 🛠️ Technologies Used

- Python 3
- File Handling
- Functions
- Conditional Statements
- Loops
- Exception Handling

## 📄 Book Record Format

Each book is stored in the following format:

```
BookID,BookName,Author,Category,Quantity
```

### Example

```
101,Python Programming,Guido van Rossum,Programming,5
102,C Programming,Dennis Ritchie,Programming,3
```

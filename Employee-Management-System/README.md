# EMPLOYEE MANAGEMENT SYSTEM

## 📌 Project Overview

The Employee Management System is a menu-driven Python application that helps manage employee records efficiently. It uses JSON file handling to store employee data permanently, allowing users to add, view, search, update, and delete employee information.

This project demonstrates Python fundamentals such as functions, loops, conditional statements, exception handling, JSON file handling, and CRUD (Create, Read, Update, Delete) operations.

---

## 🚀 Features

- Secure Login Authentication
- Add Employee Record
- View All Employee Records
- Search Employee by Employee ID
- Update Employee Details
- Delete Employee Record
- JSON File Storage
- Exception Handling
- Menu-Driven Interface

# 📒 Smart Contact Book Management System

A simple **Python-based Contact Book Management System** that allows users to manage contacts efficiently using **JSON file handling**. This project is menu-driven and supports CRUD (Create, Read, Update, Delete) operations.

---

## 📌 Features

- 🔐 User Login Authentication
- ➕ Add New Contact
- 📋 View All Contacts
- 🔍 Search Contact
- ✏️ Update Contact
- ❌ Delete Contact
- 💾 Store Data in JSON File
- ⚠️ Exception Handling
- 📂 Menu-Driven Program

---

## 🛠️ Technologies Used

- Python 3
- JSON
- File Handling
- VS Code

## 📖 Functionality

### ➕ Add Contact

- Enter Name
- Enter Phone Number
- Enter Email
- Saves contact into `contacts.json`

---

### 📋 View Contact

Displays all saved contacts.

Example:

```
Name : Shweta
Phone : 7022621086
Email : shweta.borganve@gmail.com
```

---

### 🔍 Search Contact

Searches a contact by name.

Example:

```
Enter name to search: Shweta

Contact Found

Name : Shweta
Phone : 7022621086
Email : shweta.borganve@gmail.com
```

---

### ✏️ Update Contact

Updates an existing contact.

Example:

```
Enter contact name to update: Bapa

Enter new name: Appa
Enter new phone number: 9876543210
Enter new email: appa@gmail.com
```

---

### ❌ Delete Contact

Deletes a contact by name.

Example:

```
Enter contact name to delete: Mammy

Contact Deleted Successfully!!
```

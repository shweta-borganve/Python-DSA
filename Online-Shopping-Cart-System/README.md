# 🛒 ONLINE SHOPPING CART SYSTEM

A Python-based **Online Shopping Cart System** that allows users to manage products, search for items, add products to a shopping cart, update cart items, and complete the checkout process. The application uses **JSON files** for persistent data storage, making it simple, lightweight, and suitable for learning file handling and CRUD operations in Python.

---

## 📌 Features

- 🔐 User Login Authentication
- ➕ Add New Products
- 📋 View Available Products
- 🔍 Search Products by Name
- 🛒 Add Products to Cart
- 👀 View Shopping Cart
- ✏️ Update Cart Quantity
- ❌ Remove Products from Cart
- 💳 Checkout and Generate Bill
- 🚪 Logout
- 💾 JSON-based Data Storage

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/Online-Shopping-Cart-System.git
```

2. Navigate to the project folder

```bash
cd Online-Shopping-Cart-System
```

3. Run the application

```bash
python main.py
```

## 📊 Data Storage

The application stores data in JSON files.

### users.json
Stores user login credentials.

### products.json
Stores product details such as:
- Product ID
- Product Name
- Price
- Stock Quantity

### cart.json
Stores products added to the shopping cart.
